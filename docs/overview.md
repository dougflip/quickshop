# QuickShop

## Long Term Vision

The long term vision: A realtime collaborative shopping list which understands which items you want to buy, which store you are currently shopping at, and can organize your path through the store to efficiently guide you to each item.

## MVP and Milestones

The long term vision is ambitious and there are useful milestones along the way.
The MVP would be creating a shared shopping list and then allowing the user to "shop" and mark items as they are added to the cart.

An MVP similar to above will provide a foundation for future milestones.
